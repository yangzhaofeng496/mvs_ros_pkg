配置缓存

SDK支持如下两种缓存配置的方式。您可按需选择。
  • SDK内部分配缓存：SDK内部主动分配图像缓存，用于获取图像数据。
  • 外部注册缓存：您需自行分配多个缓存，之后通过SDK接口将分配的缓存注册到SDK内部。SDK使用您注册的缓存获取图像数据。
注解
外部注册缓存需要主动调用接口注册，默认使用SDK内部缓存。

SDK内部分配缓存

您可通过 IStreamGrabber.SetImageNodeNum() 设置SDK内部图像缓存节点个数。未设置缓存节点个数时，SDK使用默认的缓存个数。
注解
IStreamGrabber.SetImageNodeNum() 需要在 IStreamGrabber.StartGrabbing() 之前调用。
如下代码演示了使用内部缓存获取图像数据的过程。
// 设置缓存节点个数（可选）
device.StreamGrabber.SetImageNodeNum(5);
// 开始取流
int result = device.StreamGrabber.StartGrabbing();
if (result != MvError.MV_OK)
{
Console.WriteLine("Start grabbing failed:{0:x8}", result);
return;
}

外部注册缓存

外部注册缓存是指您自行分配和释放图像缓存。
外部注册缓存的基本步骤如下：
  1. 调用 IStreamGrabber.GetPayloadSize() 获取足够的缓存大小及正确的内存对齐方式。
    注解
    在您修改图像相关参数（例如修改图像宽度、高度和像素格式等）后，您需重新调用该接口，重新获取缓存大小。
  2. 调用 IStreamGrabber.AllocAlignedBuffer() 分配内存。
  3. 调用 IStreamGrabber.RegisterBuffer() 将分配好的内存注册给SDK。
  4. 调用 IStreamGrabber.StartGrabbing() 开始采集图像。
结束采集后，您需取消已注册的缓存。步骤如下：
  1. 调用 IStreamGrabber.UnRegisterBuffer() 取消已经注册的缓存。
  2. 调用 IStreamGrabber.FreeAlignedBuffer() 释放缓存
    注解
    • IStreamGrabber.StartGrabbing() 前必须注册外部缓存，否则按照内部缓存取图。
    • 支持动态缓存注册，在 IStreamGrabber.StartGrabbing() 开始采集后，支持多次调用 IStreamGrabber.RegisterBuffer() 注册缓存和 IStreamGrabber.UnRegisterBuffer() 取消注册。
    • 注册的缓存可用于主动取图和回调取图。
// 获取当前配置情况下图像的负载信息
UInt64 bufLen;
UInt32 alignment;
result = device.StreamGrabber.GetPayloadSize(out bufLen, out alignment);
if (result != MvError.MV_OK)
{
Console.WriteLine("Getting payload size failed:{0:x8}", result);
return;
}
IntPtr[] pBufferList = new IntPtr[IMAGE_NODE];
for (int k = 0; k < IMAGE_NODE; k++)
{
// 用户分配的内存
pBufferList[k] = device.StreamGrabber.AllocAlignedBuffer(bufLen, alignment);
if (pBufferList[k] == IntPtr.Zero)
{
result = (int)MV_E_RESOURCE;
return;
}
// 用户分配的内存注册到SDK中
result = device.StreamGrabber.RegisterBuffer(pBufferList[k], bufLen, IntPtr.Zero);
if (result != MvError.MV_OK)
{
Console.WriteLine("Registering buffer failed:{0:x8}", result);
return;
}
}
// 开始取流
result = device.StreamGrabber.StartGrabbing();
if (result != MvError.MV_OK)
{
Console.WriteLine("Start grabbing failed:{0:x8}", result);
return;
}
//获取图像
//do something
// 停止取流
result = device.StreamGrabber.StopGrabbing();
if (result != MvError.MV_OK)
{
Console.WriteLine("Stop grabbing failed:{0:x8}", result);
return;
}
for (int k = 0; k < IMAGE_NODE; k++)
{
// 取消SDK中注册的外部缓存
result = device.StreamGrabber.UnRegisterBuffer(pBufferList[k]);
if (result != MvError.MV_OK)
{
Console.WriteLine("Unregistering buffer failed:{0:x8}", result);
return;
}
}
if (result != MvError.MV_OK)
{
Console.WriteLine("Unregistering buffer failed:{0:x8}", result);
return;
}
// 释放用户分配的内存
for (int k = 0; k < IMAGE_NODE; k++)
{
if (pBufferList[k] != IntPtr.Zero)
{
device.StreamGrabber.FreeAlignedBuffer(pBufferList[k]);
pBufferList[k] = IntPtr.Zero;
}
}
