发版说明

V4.8.0

V4.8.0版本发布于2026年5月。

【功能新增】
  • 新增 Endianness 用于设置存储字节顺序。在保存TIFF图像时，您可通过 ImageFormatInfo.ByteOrder 指定保存文件的字节顺序。
  • 支持外部注册缓存。新增 IStreamGrabber.GetPayloadSize() 、 IStreamGrabber.RegisterBuffer() 、 IStreamGrabber.UnRegisterBuffer() 、 IStreamGrabber.AllocAlignedBuffer() 、 IStreamGrabber.FreeAlignedBuffer() 接口。
    • 在您调用 IStreamGrabber.StartGrabbing() 之前，若未注册缓存，则SDK默认使用内部缓存。
    • 在您调用 IStreamGrabber.StartGrabbing() 之前，若已注册缓存（通过 IStreamGrabber.GetPayloadSize() 、 IStreamGrabber.AllocAlignedBuffer() 和 IStreamGrabber.RegisterBuffer() ），则SDK是外部注册缓存模式。
      该模式支持动态调整缓存大小。即在调用 IStreamGrabber.StartGrabbing() 之后，您仍可根据实际需求，动态调用 IStreamGrabber.RegisterBuffer() 和 IStreamGrabber.UnRegisterBuffer() 调整缓存。
      注解
      您可参考 配置缓存 中的介绍，了解相关接口调用流程。
  • 支持XoFLink协议下的Dataforward功能。
    注解
    • 通过串接采集卡，可实现将主卡接收的数据转发至从卡，实现多张采集卡同步采集同一图像源的效果。
    • 仅部分型号采集卡支持此功能。使用时，请根据场景选择合适的连接方式（串行或并行）。
  • 支持CXP采集卡的拆图功能。
  • 支持XoF采集卡的4GB以上大图卡端拆图功能。
  • 支持GigE Vision相机的整帧重传功能。
  • 针对各个子模块补充共用及特有的状态码，帮助您更准确的定位问题。详情请参见 状态码及异常 。
【功能优化】
  • 提升HB图像解码性能。
  • 优化参数导入导出功能。
  • 完善取图策略。
    • 支持采集卡下相机。
    • 支持USB3 Vision相机的UpcomingImage模式。
  • 优化USB3 Vision设备取流逻辑，提升对低性能设备的兼容性。

V4.7.0

【功能更新】
  • 调整 ISerialPort.Write() 的单次最大数据写入量为512字节。
  • 支持RGB12格式图像的渲染和保存。
    • 支持渲染RGB12像素格式的图像。
    • 支持调用IImageSaver.SaveImageToFile() [1/2]、IImageSaver.SaveImageToFile() [2/2]保存RGB12格式的图像。
  • 支持快速FileAccess功能。若相机和其固件支持，则可通过该功能，大幅提高文件的导入导出速率。
【功能更新】
  • IImageRender.DisplayOneFrame() 支持渲染 PixelType_Gvsp_YUV420SP_NV12 和 PixelType_Gvsp_YUV420SP_NV21 格式。
  • IPixelTypeConverter.ConvertPixelType() 支持将部分Bayer8（包含BayerRG8、BayerGR8、BayerGB8、BayerBG8）像素格式图像转换为RGB8 Planar像素格式图像。
  • 事件相关功能优化。
    • 单进程下，支持同一采集卡的多个实例同时注册事件。在同一进程下，假设您分别对其实例A和实例B调用 IEventGrabber.SubscribeEvent() 注册同一事件M，实例A和实例B会同时接收到事件M。
      注解
      对同一实例多次注册同一事件时，旧注册的回调函数和自定义信息会被覆盖。
    • SDK支持接收CoaXPress相机事件。
  • StreamExceptionType 下新增0x4008（ImageBufferOverflow）表示设备发送的图像数据大小超过了图像缓存区容量。
  • VisionPro插件支持VP9.23和VP9.24。
  • 优化采集卡事件性能，降低CPU占用。
