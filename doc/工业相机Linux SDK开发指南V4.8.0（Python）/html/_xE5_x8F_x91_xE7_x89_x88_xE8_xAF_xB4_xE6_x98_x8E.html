发版说明

V4.8.0

V4.8.0版本发布于2026年5月。

【功能新增】
  • 支持Bayer BRGG8像素格式图像的采集、解析、保存等功能。
  • 完善 CameraParams_header.MV_GIGE_DEVICE_INFO ，新增以下成员。
    • nHostIP：枚举设备时，返回当前占用该相机的主机IP地址（需相机支持）。
    • nMulticastIP/nMulticastPort：组播IP地址和组播端口。
    • nGenTLType：相机类型（0：GigE Vision设备，1：虚拟GigE Vision设备，2：自研网卡下GigE Vision设备）。
  • 支持指定保存TIFF图像时的字节顺序。您可通过 CameraParams_header.MV_CC_SAVE_IMAGE_PARAM 或 CameraParams_header.MV_SAVE_IMAGE_TO_FILE_PARAM_EX 中的nEndian字段来配置该字节顺序。
  • MV_CC_InputOneFrameEx() 支持输入HB和JPEG图像。
  • MV_GIGE_IssueActionCommand() 支持并行操作。
  • 支持XoFLink协议下的Dataforward功能。
    注解
    • 通过串接采集卡，可实现将主卡接收的数据转发至从卡，实现多张采集卡同步采集同一图像源的效果。
    • 仅部分型号采集卡支持此功能。使用时，请根据场景选择合适的连接方式（串行或并行）。
  • 支持CXP采集卡的拆图功能。
  • 支持XoF采集卡的4GB以上大图卡端拆图功能。
  • 支持GigE Vision相机的整帧重传功能。
  • 针对各个子模块补充共用及特有的状态码，帮助您更准确的定位问题。详情请参见 状态码 。
【功能优化】
  • 提升HB图像解码性能。
  • 优化参数导入导出功能。
  • 完善取图策略。
    • 支持采集卡下相机。
    • 支持USB3 Vision相机的UpcomingImage模式。
  • 优化USB3 Vision设备取流逻辑，提升对低性能设备的兼容性。

V4.7.0

【功能新增】
  • 支持RGB12格式图像的渲染和保存。
    • 支持通过GDI、D3D和OpenGL模式渲染RGB12像素格式的图像。
    • 支持调用 MV_CC_SaveImageEx3() ， MV_CC_SaveImageToFileEx() 和 MV_CC_SaveImageToFileEx2() 保存RGB12格式的图像。
  • MV_CC_DisplayOneFrameEx() 和 MV_CC_DisplayOneFrameEx2() 支持渲染 PixelType_Gvsp_YUV420SP_NV12 和 PixelType_Gvsp_YUV420SP_NV21 格式。
    注解
  • MV_CC_ConvertPixelTypeEx() 支持将Bayer像素格式图像转换为RGB Planar像素格式图像。
  • 事件相关功能优化。
    • 单进程下，支持同一采集卡的多个句柄同时注册事件。在同一进程下，假设您分别对其句柄A和句柄B调用 MV_CC_RegisterEventCallBackEx() 注册同一事件M，句柄A和句柄B会同时接收到事件M。
      注解
      对同一句柄多次注册同一事件时，旧注册的回调函数和自定义信息会被覆盖。
    • SDK支持接收CoaXPress相机事件。
【示例程序更新】
新增如下示例程序：
  • Recording.py ：演示如何将相机拍摄到的画面存储为视频录像。
  • Grab_LineStart.py ：演示在指定线程设置线阵相机取流。
  • BasicDemoLineScanCamera.py ：演示线阵相机的基础使用方式，包括初始化SDK、枚举设备、创建实例和句柄等。
