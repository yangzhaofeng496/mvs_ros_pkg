Release Notes

V4.8.0_May/2026


New Features
  • Added the enumeration to support setting byte order when saving TIFF images: Endianness . You can specify the byte order for the file to be saved via ImageFormatInfo.ByteOrder .
  • Added the following APIs to support registering external buffers to SDK: IStreamGrabber.GetPayloadSize() , IStreamGrabber.RegisterBuffer() , IStreamGrabber.UnRegisterBuffer() , IStreamGrabber.AllocAlignedBuffer() , IStreamGrabber.FreeAlignedBuffer() .
    • If buffer is not registered before IStreamGrabber.StartGrabbing() is called, the internal buffer will be used by default.
    • if buffer is registered via IStreamGrabber.GetPayloadSize(), IStreamGrabber.AllocAlignedBuffer(), and IStreamGrabber.RegisterBuffer() before IStreamGrabber.StartGrabbing(), the registered external buffer will be used.
      The buffer size can be adjusted dynamically, namely after IStreamGrabber.StartGrabbing(), you can call IStreamGrabber.RegisterBuffer() and IStreamGrabber.UnRegisterBuffer() to adjust the buffer size as needed.
      Note
      Refer to Buffer Configuration for the calling flow of related APIs.
  • Supported data forwarding in XoFLink protocol.
    Note
    • By connecting the frame grabbers in series, data received by the main frame grabber can be forwarded to the sub frame grabbers, allowing multiple frame grabbers to synchronously capture the same image source.
    • Only some frame grabbers support data forwarding. You can select the appropriate connection method for your scenario (connection in series or parallel).
  • Supported splitting image via CoaXPress frame grabber.
  • Supported splitting large image over 4 GB via XoF frame grabber.
  • Supported frame retransmission for GigE Vision camera.
  • Added some status codes in Status Codes.
Improvements
  • Improved performance of HB image decoding.
  • Optimized parameter importing/exporting.
  • Optimized image acquisition strategy.
    • Supported cameras connected to frame grabber.
    • Supported UpcomingImage mode of USB3 Vision camera.
  • Optimized the image acquisition logic of USB3 Vision device and improve the compatibility with low-performance devices.

V4.7.0_November/2025

New Features
  • Adjusted the maximum single write data size of ISerialPort.Write() to 512 bytes.
  • Supported rendering and saving RGB 12 format images.
    • Supported rendering RGB 12 format images.
    • Supported calling IImageSaver.SaveImageToFile() [1/2], IImageSaver.SaveImageToFile() [2/2] to save RGB 12 format images.
  • Supported the fast FileAccess feature. If the camera and its firmware support it, this feature can significantly increase the file import and export speed.
Improvements
  • Optimized the API IImageRender.DisplayOneFrame() to support rendering images in PixelType_Gvsp_YUV420SP_NV12 and PixelType_Gvsp_YUV420SP_NV21 formats.
  • Optimized the API IPixelTypeConverter.ConvertPixelType() to support converting pixel format Bayer8 (including BayerRG8, BayerGR8, BayerGB8, and BayerBG8) to RGB8 Planar format.
  • Optimized event related features.
    • Supported registering events for multiple instances of a frame grabber at the same time in a single-process environment. In a process, if you call IEventGrabber.SubscribeEvent() for instance A and instance B respectively to register the same event M, both instance A and instance B will receive event M at the same time.
      Note
      When registering the same event multiple times for the same instance, the previously registered callback function and custom information will be overwritten.
    • SDK supported receiving CoaXPress camera event.
  • Added 0x4008 (ImageBufferOverflow) to StreamExceptionType to indicate that the image data sent by the device has exceeded the capacity of the image buffer.
  • VisionPro plugin supports VP9.23 and VP9.24.
  • Optimized the performance of frame grabber events, reducing CPU usage.
