Buffer Configuration

The SDK supports the following two buffer configuration methods.
  • SDK Allocates Internal Buffer: The SDK internally allocates image buffers for getting image data.
  • Register External Buffer to SDK: You need to allocate multiple buffers and register the allocated buffers to the SDK via APIs, and then the SDK will use the registered buffers to get image data.
Note
You need to actively call the APIs to register external buffers, and the SDK uses its internal buffers by default.

SDK Allocates Internal Buffer

You can call IStreamGrabber.SetImageNodeNum() to set the number of internal image buffer nodes. If the number of buffer nodes is not set, the SDK will use the default number of buffers.
Note
IStreamGrabber.SetImageNodeNum() should be called before IStreamGrabber.StartGrabbing().
The sample codes show how to get image data using internal buffers.
// (Optional) Set the number of buffer nodes
device.StreamGrabber.SetImageNodeNum(5);
// Start grabbing images
int result = device.StreamGrabber.StartGrabbing();
if (result != MvError.MV_OK)
{
Console.WriteLine("Start grabbing failed:{0:x8}", result);
return;
}

Register External Buffer to SDK

You can allocate and release external image buffers to and from the SDK.
The basic steps for registering external buffers are as follows:
  1. Call IStreamGrabber.GetPayloadSize() to get sufficient buffer size and correct memory alignment methods.
    Note
    After editing image related parameters, such as image width, image height, and pixel format, you need to call this API to get the buffer size again.
  2. Call IStreamGrabber.AllocAlignedBuffer() to allocate memory.
  3. Call IStreamGrabber.RegisterBuffer() to register allocated memory as a buffer to the SDK.
  4. Call IStreamGrabber.StartGrabbing() to start grabbing image.
After image acquisition, you need to cancel the registered buffer as follows:
  1. Call IStreamGrabber.UnRegisterBuffer() to cancel the registered buffer.
  2. Call IStreamGrabber.FreeAlignedBuffer() to release the buffer.
    Note
    • Before calling IStreamGrabber.StartGrabbing(), it is required to register external buffer to the SDK, or internal buffer will be used to get images.
    • It is supported to dynamically register buffers. After calling IStreamGrabber.StartGrabbing() to starting image grabbing, you can call IStreamGrabber.RegisterBuffer() and IStreamGrabber.UnRegisterBuffer() for multiple times.
    • The registered buffer can be used to get images via polling function and via callback function.
// Get the payload information of images in the current configuration
UInt64 bufLen;
UInt32 alignment;
result = device.StreamGrabber.GetPayloadSize(out bufLen, out alignment);
if (result != MvError.MV_OK)
{
Console.WriteLine("Getting payload size failed:{0:x8}", result);
return;
}
IntPtr[] pBufferList = new IntPtr[IMAGE_NODE];
for (int k = 0; k < IMAGE_NODE; k++)
{
// Allocate external aligned memory
pBufferList[k] = device.StreamGrabber.AllocAlignedBuffer(bufLen, alignment);
if (pBufferList[k] == IntPtr.Zero)
{
result = (int)MV_E_RESOURCE;
return;
}
// Register the allocated memory to the SDK
result = device.StreamGrabber.RegisterBuffer(pBufferList[k], bufLen, IntPtr.Zero);
if (result != MvError.MV_OK)
{
Console.WriteLine("Registering buffer failed:{0:x8}", result);
return;
}
}
// Start grabbing images
result = device.StreamGrabber.StartGrabbing();
if (result != MvError.MV_OK)
{
Console.WriteLine("Start grabbing failed:{0:x8}", result);
return;
}
// Get images
//do something
// End grabbing images
result = device.StreamGrabber.StopGrabbing();
if (result != MvError.MV_OK)
{
Console.WriteLine("Stop grabbing failed:{0:x8}", result);
return;
}
for (int k = 0; k < IMAGE_NODE; k++)
{
// Cancel the external buffer registered to the SDK
result = device.StreamGrabber.UnRegisterBuffer(pBufferList[k]);
if (result != MvError.MV_OK)
{
Console.WriteLine("Unregistering buffer failed:{0:x8}", result);
return;
}
}
if (result != MvError.MV_OK)
{
Console.WriteLine("Unregistering buffer failed:{0:x8}", result);
return;
}
// Release user-allocated memory
for (int k = 0; k < IMAGE_NODE; k++)
{
if (pBufferList[k] != IntPtr.Zero)
{
device.StreamGrabber.FreeAlignedBuffer(pBufferList[k]);
pBufferList[k] = IntPtr.Zero;
}
